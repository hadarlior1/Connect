# Architecture of the template

Stack: React 19 + Vite + TypeScript + Tailwind v4 (`@tailwindcss/vite`), Vitest (jsdom).
Static site on Cloudflare Workers Static Assets (SPA fallback). No backend — progress, quiz scores,
language and player settings live in the visitor's `localStorage`.

## Behavior worth knowing

- **Fit to the window at 100% zoom.** On wide screens the screenshot fills the full width and is
  zoomed so the highlighted area takes ~60% of it (capped at 1.9×), with the rest reachable by
  scrolling inside the frame. Its height = window height minus `--chrome` (21rem; 23.75rem for steps
  with a tip/warning — keep `useFitHeight` in StepStage in sync). If you change the header, stepper
  or player height, re-measure: subtitles and notes must end above the player bar.
- **Only existing media is requested.** The host answers missing files with the SPA page, which some
  browsers never reject. `videos.ts` lists what exists; English narration is used only when every
  file exists and is non-empty (`EN_NARRATION`).
- **Quiz** opens after the last step of a chapter, once per chapter (welcome mode only).
  **Certificate** opens on "סיום ההדרכה"; printing shows only the certificate.
- **English mode** switches `dir` to ltr, uses `lessons.en.ts`, skips the Hebrew videos and narrates
  in English. Screenshots stay in Hebrew, so English scripts name each label in English with the
  Hebrew label in parentheses.
- Nav drawer translate classes must be scoped `max-xl:rtl:` / `max-xl:ltr:` — an unscoped `rtl:`
  variant beats `xl:translate-x-0` and hides the docked sidebar.

## Branding checklist

| Where | What to change |
|---|---|
| `public/brand/` | Logo (transparent PNG/SVG), presenter cut-out (frame from a video, or a photo), og.jpg |
| `src/styles.css` `:root` | `--brand`, `--violet`, `--accent` (+ `--rgb-*`) from the logo colors |
| `src/lib/i18n.ts` | `brand`, `course`, `courseFull`, `presenter`, `presenterRole`, **`heroPromise`** (a concrete, true promise — check the minutes against the real recordings), `heroSub`, `trust` — in he and en |
| `src/content/brand.ts` | `SUPPORT` phone / WhatsApp / email (ask; never invent) |
| `index.html` | `<title>`, description, `og:*` (absolute URL of og.jpg), theme-color |
| `src/lib/progress.ts`, `speech.ts`, `i18n.ts`, `App.tsx`, `Quiz.tsx`, `Certificate.tsx` | localStorage keys (`muni-training-*`, `epr-training-*`) → a new prefix per site |
| `wrangler.jsonc`, `package.json` | `"name"` |
| tests | Strings that assert the old names |
